## cl-camp3

### Instructions

"start looking ..."

Create a file named `look` that will search for and display, within the current directory and all its subdirectories:

- All files and directories whose names start with the letter `a`, or
- All files that end with the letter `z`, or
- All files that start with `z` and end with `a!`
